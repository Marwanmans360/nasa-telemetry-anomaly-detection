# Multivariate Time-Series Anomaly Detection

## Objective
Build an anomaly detection system to identify abnormal behavior in telemetry sensor data.

## Dataset
NASA SMAP/MSL anomaly detection dataset.

## Problem Type
Anomaly detection on multivariate time-series data.

## Expected Output
The model should produce an anomaly score or binary label for each time window.

## Evaluation Metrics
- Precision
- Recall
- F1-score
- Precision-Recall AUC
- False alarm rate
